# File Browser

## Overview

File Browser provides web-based access to files stored on the home server.

## Purpose

- Browse files remotely
- Upload and download files
- Create and delete folders
- Manage media files
- Access server storage through a web interface

## Deployment Method

Deployed using Docker Compose through OpenMediaVault.

## Access

Available through the local network and remotely through Tailscale.

## Storage

Managed files are stored on the server storage drive and shared through SMB where required.

## Future Improvements

- User-specific permissions
- HTTPS access
- Integration with Homepage Dashboard
